# Accordion

Base UI compound accordion: Accordion root, AccordionItem, AccordionTrigger (includes an h3 header), AccordionContent (animated panel with an inner padding wrapper). Replaces the standalone accordion.tsx. All parts forward native props, refs, render composition and state-based className. Trigger headingProps customizes the heading wrapper, including its level via render.

Root controls color (inherit default, primary, neutral, success, error), variant (ghost default, fill, tonal, outline), and size (md default, xs through xl). Color controls variant backgrounds and borders. Fill uses palette foreground pairs; inherit fill uses a subtle currentColor tint and inherited text. Other variants inherit text. Palette variants use existing semantic Tailwind colors directly. Geometry, motion and inherited surface tokens are defined in src/app/styles/theme/semantics.css. Do not define component-local palette variables on the root. Base UI still provides --accordion-panel-height dynamically. Styles use a named CSS Module layer, zero-specificity selectors, logical properties and em padding. Nest responsive media rules in their associated selectors.

Preserve Base UI value arrays, defaultValue, onValueChange, multiple, disabled, keepMounted, hiddenUntilFound and per-item disabled/onOpenChange. Keyboard activation uses Enter/Space and ordinary Tab navigation (orientation/loopFocus are deprecated in Base UI 1.9). Content className applies to the actual panel, not its inner wrapper. Reduced motion disables panel and chevron transitions. Stories test the appearance matrix and interactive states with a11y.test set to error; unit tests verify contracts and native props/refs.
