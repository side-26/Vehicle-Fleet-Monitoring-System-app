# Text field

Owns the standalone Base UI Input composition with Field labels, descriptions, required markers, sizes, colors, and variants. No form provider is required. Native input props and refs reach the control. Styles use em sizing and semantic colors. Stories and unit tests cover the public API.

TextField composes InputGroupInput inside InputGroup and renders children as addons. Group styles own the border, background, and focus outline; native props and className reach the input.
