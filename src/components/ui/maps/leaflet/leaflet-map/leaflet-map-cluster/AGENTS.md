# LeafletMapCluster

Thin dependency boundary over react-leaflet-cluster's MarkerClusterGroup. Keep vendor runtime imports behind next/dynamic with ssr:false; public and loader types must use type-only imports. Forward every native cluster option, event, child and Leaflet instance ref through instanceRef, matching neighboring adapters. Import the required vendor cluster CSS here. No local CSS Module is needed because this adapter has no custom styles or DOM wrapper. Compose under LeafletMap with a finite maxZoom (or a tile layer providing one) and MapPointer children. Consumers import this adapter rather than the vendor. Native update and clustering behavior remain the dependency's responsibility. Unit tests verify props, event updates, children and refs with real layers; integration tests cover dynamic marker membership. Stories show OpenStreetMap, clustered markers, disabled clustering at a zoom threshold, and spiderfy options.
