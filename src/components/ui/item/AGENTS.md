# Item

Reusable informational list item composed from Item (li), ItemMedia (decorative div), ItemContent (div), ItemTitle (h3) and ItemDescription (p). ItemGroup wraps related items in a native ul, forwards native list props and refs, and provides a reset vertical layout. Prefer a named ItemGroup around Item components. Media is hidden from assistive technology; put meaningful content and interactive controls in ItemContent. Each part forwards native props and refs. The color prop defaults to inherit and supports primary, neutral (foreground), error and success. Color controls the outline border or muted background through --item-color; text and media retain inherited text color. The variant prop supports default (transparent, the default), outline and muted. Uses compact typography. Parent lists own layout and separators. Styles live in the local named CSS layer with zero-specificity selectors.
