# Textarea form field

Owns the typed React Hook Form adapter for TextareaField. Requires the existing Form provider and uses useController without duplicate registration. Binds name, value, change, blur, disabled state, and focus ref; defaults belong in Form. Derives requiredness from rules or the explicit required prop. Validation errors replace helper text. Pass the configured color unchanged; the base field CSS selects error/success presentation through aria-invalid and data-validated. React Hook Form owns validation and exposes its state through those attributes. Native textarea settings, rows, autoResize, and field variants pass through. Base TextareaField owns appearance. Tests cover provider binding, validation, focus, corrected submission, and helper restoration.
