# Viewport Suspense

ViewportSuspense accepts fallback and dynamicMain React elements plus threshold (default 0.35). Uses the shared intersection hook to mount dynamicMain once after entry, keeping its state when scrolled away. The fallback renders during SSR/before entry and under Suspense when content suspends. Pass the same fallback to next/dynamic through its loading option so its internal loading boundary also displays it. Declare next/dynamic at module scope in a client caller; passing a statically imported component defers rendering but does not split its bundle. Import failures bubble to the nearest error boundary. Native div props and refs are forwarded. The CSS Module reserves a minimal observable block size even with an empty fallback; callers should reserve realistic space through the fallback or wrapper style to avoid layout shift. Tall wrappers must have enough of their area visible to satisfy the requested threshold. Unsupported IntersectionObserver reveals content using the shared hook fallback. Unit tests cover prop composition; integration tests use real next/dynamic and a controlled observer.
