# Viewport Suspense

ViewportSuspense accepts fallback and dynamicMain React elements plus threshold (default 0.35). Uses the shared intersection hook to mount dynamicMain once after entry, keeping its state when scrolled away. The same fallback renders during SSR/before entry and under Suspense while the dynamic component loads. Declare React.lazy/next/dynamic at module scope in a client caller; passing a statically imported component defers rendering but does not split its bundle. Import failures bubble to the nearest error boundary. Native div props and refs are forwarded. The CSS Module reserves a minimal observable block size even with an empty fallback; callers should reserve realistic space through the fallback or wrapper style to avoid layout shift. Tall wrappers must have enough of their area visible to satisfy the requested threshold. Unsupported IntersectionObserver reveals content using the shared hook fallback. Unit tests cover prop composition; integration tests use real Suspense/lazy and a controlled observer.
