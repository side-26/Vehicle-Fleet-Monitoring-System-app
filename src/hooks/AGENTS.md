# Shared hooks

Contains reusable client hooks. useFormField centralizes React Hook Form provider/controller binding, required-rule derivation, and validation metadata for field adapters. Keep control-specific value conversions and visual rendering in each adapter; form default values belong in the Form provider.

useFormField unit tests run in jsdom with real React Hook Form providers and controllers. Cover required-rule precedence, pristine/touched/dirty/submitted validation metadata, field bindings, disabled submission, and unregister behavior without mocking the form library.

useIsMobile uses useSyncExternalStore to read whether the viewport is below a configurable breakpoint (768 by default), resubscribes when that breakpoint changes, and removes media-query listeners on cleanup. It returns false during server rendering and initial hydration before synchronizing with the client viewport. Its unit tests use a jsdom environment with real EventTarget subscriptions to verify boundaries, updates, cleanup, and hydration without mismatches.

useToast() takes no options and wraps the native Base UI useToastManager inside the existing Toaster/ToastProvider. Its add(options) accepts duration in milliseconds (default 3000; zero is persistent) align (default top-center), and native type, which automatically determines the glass surface color (info, primary, success, error, warning; primary for omitted/loading/unknown types). Duration overrides an explicit native timeout. Alignment supports top/bottom with logical start/center/end and is stored separately from caller data. Native update, close and promise remain available with native timeout options. The Toast renderer groups notifications by alignment inside one viewport. Tests use the real provider and fake timers to verify expiry, persistence, per-toast overrides, alignment and shared manager behavior.

useAnimationRunOnIntersectionObserver returns a callback ref and isVisible for viewport-triggered animations. Defaults to 10% visibility and once per hook lifetime. once:false follows entry/exit for replay. Supports native root/rootMargin/threshold options, stable inline threshold arrays, observer cleanup and stale notification guards. Without IntersectionObserver, attached content is revealed. Attach ref to the section and use isVisible to toggle an animation class or data attribute; do not unmount the observed section while waiting. Tests run in jsdom with a controllable observer boundary.
